# 🎓 Career Finder App (MERN Stack)

A responsive, full-stack Web Application built using the **MERN** stack (MongoDB, Express, React, Node.js). The app allows users to search and explore various career options, including job descriptions, key technical skills required, and estimated salary ranges.

---

## ✨ Features

- 🔍 **Real-time Search:** Instantly filter through career options by title or skill set.
- 💼 **Detailed Insights:** View descriptions, key skill requirements, and average salary ranges for each career.
- 🎨 **Responsive UI:** Clean, modern, and mobile-friendly interface built with React.
- ⚡ **RESTful API:** Robust Node.js & Express backend serving career data from MongoDB.

---

## 🛠️ Tech Stack

### Frontend
- **React.js** (Vite)
- **Axios** (for API calls)
- **CSS / Inline Styles**

### Backend
- **Node.js** & **Express.js**
- **MongoDB** (with Mongoose ORM)
- **CORS** (Cross-Origin Resource Sharing)
